# 从专栏到可参与环节

来源：用户提供的“专栏 3 新产业新赛道培育发展”和“专栏 7 新型基础设施建设”两张图片，已视觉阅读；对应十五五纲要相关专栏。下表前两列概括图片内容，后两列是项目整理的应用假设，不是官方指定商机、准入判断或已验证需求。

## 专栏 3：不要把十个产业当作同一种机会

| 方向 | 材料列出的任务重点 | 可研究的参与环节 | 先验证什么 |
| --- | --- | --- | --- |
| 集成电路 | 制程、装备材料零部件、处理器和存储、先进技术 | 工艺配套、专业检测、质量与供应链服务 | 技术能力、客户认证、供货周期和适用限制 |
| 具身智能 | 实训场、虚实协同训练、模型算法、本体与部件、应用 | 数据质量、场景评测、行业集成、培训和维护 | 场景是否真实需要机器人、部署可靠性和任务收益 |
| 生物制造 | 酶制剂、种质设计、发酵、医药与能源应用 | 质量管理、检测、工艺/设备服务 | 产品与活动类型、资质、技术验证和客户 |
| 新型电池 | 关键材料、制造设备工艺与终端应用 | 检测、质量追溯、生产服务、生命周期配套 | 性能与安全验证、客户导入、成本与采购 |
| 商业航天 | 星箭技术、可重复使用、规模化与发射能力 | 在合规且具备专业能力前提下研究民用供应链配套 | 技术门槛、客户集中度、资质和适用限制 |
| 国产大飞机 | 产能、供应链、机型及发动机验证 | 航空产业配套、质量与专业服务 | 认证、合格供应链、长期交付与现金流 |
| 低空装备 | 机型、动力、运行管理与安全保障 | 民用场景集成、运营支持、维护与安全管理 | 场景、地区、运行条件与经济性，不假定能直接飞行运营 |
| 绿色氢能 | 制氢、储运、基础设施与绿色燃料、终端应用 | 专业检测、设备服务、监测与工业应用配套 | 能源与客户成本、试点、技术安全和项目资格 |
| 脑机接口 | 软硬件、编码算法、语料库及诊疗/康复等场景 | 在专业监管条件下研究数据、测试和设备配套 | 医疗属性、证据、资质、数据和使用边界 |
| 高端医疗器械 | 影像、放疗、手术机器人、生命支持、植介入器械 | 合规供应、质量、售后和专业能力建设 | 具体器械和经营许可、临床证据、采购与回款 |

初学者、个体创业者、专业服务商与资本密集型技术企业的适合位置不同。海外供应商还需区分向中国供货、合作研发、授权、本地经营和直接投资。

## 专栏 7：建设目标与运行价值分别判断

| 设施 | 材料中的建设/运行任务 | 机会研究问题 |
| --- | --- | --- |
| 全国一体化算力网 | 超算/通算/智算、公有云、监测调度、资源与运营标准 | 是建更多设备，还是提高已有资源利用率？谁承担电力与运维成本？ |
| 卫星互联网 | 星座、应用、需求统筹、遥感数据共享与综合服务 | 用户需要哪个具体民用服务？数据和经营条件是什么？ |
| 信息通信网络 | 光网、5G-A、6G 研发验证、传输与普遍服务 | 研究建设、运维、行业应用各环节的客户，不把基站目标转为个人订单 |
| 数据基础设施 | 标识、身份认证、接入管理、流通利用与安全防护 | 是否有经过授权的数据、明确互通需求和实际付款方？ |
| 低空基础设施 | 场景、航路、起降与通信导航监视气象等设施 | 场景是否成立、谁运营、谁付费、当地怎样实施？ |
